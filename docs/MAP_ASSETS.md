# 大地图素材与坐标

## 素材职责划分

| 素材 | 用途 | 尺寸 |
|---|---|---|
| **地形底图** | 大地图总览的底 | 1024×1024 |
| **势力色标记** | 总览上表示城池归属与规模 | 程序绘制 |
| **城池美术**(36 张) | **放大/进城后**使用,不上总览 | 1024×1024 透明 PNG |

> 总览图的职责是「一眼看清势力归属」,精细城池美术在这个尺度下
> 既看不清归属又互相遮挡。原版用不同颜色的小方块是正确设计。

## 地形底图的生成方式

**必须以原版 `lib1.jg` 作为参考图**(走 `/v1/images/edits`),
否则海岸线与水系会漂移,36 个固定城池坐标全部失效。

prompt 里有一条关键约束:

> 参考图上那些浅灰白色、粗细均匀、把各处连接起来的线条是【道路】,不是河流。
> 新图中必须把它们画成【土路】…绝对不能画成河流、水道或蓝色的东西。

不写这句的话,模型会把道路转译成蓝色水系(实测踩过)。

## 坐标映射

原版城池坐标是 `bE[y][x]`,像素 = 格 × 6,基准画布 176×220。
新底图是 1024×1024,两者不是简单缩放。

映射参数通过**自动拟合**得到:以土路颜色做掩膜、求距离变换,
网格搜索使「36 个城池锚点到最近路面的总距离」最小。

```json
{ "x0": -12, "y0": 18, "x1": 182, "y1": 198 }
```

```
屏幕x = (格x*6 + 4 - x0) * 1024/(x1-x0)
屏幕y = (格y*6 + 4 - y0) * 1024/(y1-y0)
```

平均偏离路面 **4.7 px**(1024 尺度)。
对照:直接用 (0,0,176,220) 的朴素映射是 10.8 px。

数据:`extract/mapgen/map-fit.json`

## 城池分级

| 等级 | 数量 | 代表 |
|---|---|---|
| 1 帝都 | 2 | 洛阳、长安 |
| 2 州都 | 5 | 邺城、成都、建业、襄阳、陈留 |
| 3 大郡城 | 10 | 江陵、寿春、汉中… |
| 4 郡城 | 11 | 上庸、梓桐、会稽… |
| 5 边城 | 5 | 武威、西平、襄平、山越… |
| 6 寨堡 | 3 | 云南、建宁、荑州 |

分级 = 游戏数据(人口/农商/枢纽度) + 历史地位,冲突时以历史为准。

## 脚本

- `extract/mapgen/overview.py` — 生成总览图(地形+标记+标签)
- `extract/mapgen/compose2.py` — 把城池美术贴到地图上(放大视图用)

## 踩过的坑

1. **预览用 `pattern:checkerboard` 会把彩色图转成灰度** ——
   ImageMagick 的棋盘格是灰度色彩空间,合成时污染结果。
   必须先 `-colorspace sRGB`。曾因此误判城池素材「生成成了黑白」。
2. **PIL 打不开 `PingFang.ttc`** —— `os.path.exists` 为真但
   `truetype()` 抛异常,回退到默认位图字体,中文变方框。
   可用的是 `/System/Library/Fonts/STHeiti Medium.ttc`。
