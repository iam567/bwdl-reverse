# 武将立绘 Prompt 体系

## 核心原则:STYLE_ANCHOR 逐字不变

239 张头像的**风格一致性**是整个项目最大的技术风险。
解法是把风格词和内容词严格分开:

```
STYLE_ANCHOR  ← 所有图共用，一个字都不改
  写实厚涂油画 / 土褐青灰暗金低饱和 / 单一深色背景 /
  左上单光源侧逆光 / 严格半身 / 人物占 70% / 禁止任何文字

主体描述      ← 唯一变化的部分，由属性推导
```

风格词只要跟着内容一起漂移，整套图就散了。

## 身份判定链(顺序不能换)

```
1. 方士术士 mystic    兵力 == 0 且 计策点 == 300     全表仅 4 人
2. 女性     FEMALE    ID 白名单                      全表 20 人
3. 名将特例 ICONIC    姓名匹配                        9 人
4. 文武倾向 role      智力 − 武力 的差值              其余
```

### 为什么 mystic 必须排在最前

管辂 / 南斗 / 于吉 / 北斗 的武智被人为拉平到 105–120,
会骗过「智−武 差值」判定 → 被误判成武官 → 给了铠甲。
但他们兵力是 0(不带兵)、计策点 300(纯法术型),这个组合全表唯一。

> 实际踩过:第一版生成的管辂穿着鳞甲披毛皮,像个山地武官。

### 为什么性别必须用 ID 白名单

**原始数据表没有性别字段。** 靠名字会误判 ——
「董茶奴」(ID 190)听着像女性,实际是南蛮男将董荼那。

白名单是**逐张比对 228 张原始头像**后确认的:

```
30  蔡琰    33  鲍三娘  41  辛宪英  74  卞氏
82  张春华  130 小乔    131 大乔    132 吴国太
134 孙尚香  141 孙氏    149 孙鲁班  179 黄月英
187 祝融夫人 188 花鬘   197 貂蝉    198 吕玲绮
214 马云禄  216 蔡氏    225 刘氏    226 蔡氏(变体)
```

同时排查了 12 个画风偏中性的男性(献帝/南斗/曹叡/陈登/袁尚/
孙权/孙诩/朱桓/陆抗/诸葛亮/董茶奴/曹丕),确认全部为男性。

## 女性分支

**绝不复用男性特征函数** —— 那里有「短须」「虬髯」「魁梧」。

| 细分 | 判据 | 形象 |
|---|---|---|
| 女武将 warrior_f | 武力 ≥ 75 | 合身女式轻甲、收腰、战裙 |
| 才女 talent_f | 智力 ≥ 85 | 不着甲、广袖深衣 |
| 仕女 noble_f | 其余 | 曲裾深衣或襦裙 |

年龄单列:`ELDER_F`(吴国太)、`MATRON_F`(卞氏/蔡氏/刘氏)。

12 位既定形象过强的走 `ICONIC_F` 显式覆盖
(貂蝉/二乔/孙尚香/祝融夫人/花鬘/黄月英/蔡琰/吕玲绮/马云禄/鲍三娘/孙鲁班)。

女性 prompt 追加 `FEMALE_NEGATIVE`:

```
严禁：胡须、络腮胡、男性化面部轮廓、男性体格。
同时避免：现代服饰、暴露或性化的着装、比基尼、
         过度夸张的身材比例、动漫萌系画风。
```

## 其它已修的坑

- **兵种不能决定服饰主体。** 第一版把诸葛亮写成「水军轻甲腰悬短刀」,
  因为他的兵种字段是 2(水军)。兵种是战斗属性,不是身份。
  现在只做配饰点缀,文士与方士不挂兵器。
- **南斗是年轻男子**,不是白须老者(`MYSTIC_YOUNG`)。原画核对发现。
- 判断顺序:`wu >= 60` 的分支曾排在 `zhi >= 95` 之前,
  导致高智低武的谋士走错分支。

## 重新生成

```bash
node build-catalog.js officers.csv   # 输出 assets.json
```

线上更新 prompt 时只覆盖 `prompt` 与 `meta` 字段,
保留 `status` / `file`,已生成的图不会丢。
