# 城池连通图

大地图不是自由移动,而是一张**固定的无向图**。
甲、乙、丙三城若甲-乙-丙串联,甲**不能**直接到丙。

## 数据来源

硬编码在 `b.java` 的构造函数里,不在任何数据文件中:

```java
byte[][] byArrayArray = new byte[37][];   // 下标 1..36，0 不用
byArrayArray[1]  = new byte[]{3, 5};       // 西平 → 武威、天水
byArrayArray[9]  = new byte[]{5, 6, 10, 14};
...
this.D = byArrayArray;                     // D[城][k] = 第 k 个邻接城
byte[] byArray2 = new byte[37];
byArray2[1] = 2;                           // E[城] = 邻接数量
...
this.E = byArray2;
```

导出数据:`extract/data/city-adjacency.json`、`extract/data/city-edges.csv`

## 图的性质(已验证)

| | |
|---|---|
| 城池 | 36 |
| 无向边 | 52 |
| 对称性 | 完全对称,无单向边 |
| 连通性 | 全图连通,无孤岛 |
| 度分布 | 1度×6, 2度×10, 3度×7, 4度×9, 5度×3, 6度×1 |
| 直径 | 9 步(武威 ↔ 襄平) |
| `E[]` 校验 | 与 `D[]` 实际长度完全一致 |

## 三个指令共用这张图

| 指令 | 目标判定 | 源码 |
|---|---|---|
| 移动 | `i[目标] == i[当前]` 同势力 | `Q(byte)` b.java:8800 |
| 输送 | `i[目标] == i[当前]` 同势力 | `R(byte)` b.java:8816 |
| 战争 | 异势力 **且** 非同盟(查 `X[]`/`W`) | b.java:9075 |

`i[城]` = 该城君主的武将 ID,等值即同一势力。
