# 资源格式

## `.jg` —— 伪装的 PNG

`res/*.jg` 共 74 个。格式极简:**把 PNG 的前 16 字节换成随机数据**,其余原封不动。

```
标准 PNG:  89504E470D0A1A0A 0000000D 49484452 | 宽(4) 高(4) 位深 色彩类型 ...
           └─ 签名 8 字节 ─┘ └ 块长 ┘ └IHDR┘
.jg:       ←——— 随机 16 字节 ———→         | 宽(4) 高(4) ...
```

还原:把前 16 字节替换为 `89504E470D0A1A0A0000000D49484452`。
71/74 个文件的 IHDR CRC32 校验通过,证明还原正确。

**剩下 3 个不是图片**,是伪装成 `.jg` 的 UTF-8 CSV:

| 文件 | 内容 |
|---|---|
| `lib114.jg` | 君主表 7×4 |
| `lib115.jg` | 城池表 36×22 |
| `lib116.jg` | 武将表 228×16 |

转换脚本:`tools/unjg.py`

## `res/map/*.map` —— 战斗地图

36 张,明文 CSV,**32 列 × 20 行**,地形 ID 0–12。

实测分布(全 36 张合计):

| ID | 出现次数 | 占比 |
|---|---|---|
| 0 | 11,706 | 50.8% |
| 6 | 4,241 | 18.4% |
| 5 | 2,124 | 9.2% |
| 11 | 1,103 | 4.8% |
| 12 | 847 | 3.7% |
| 7/8 | 458/459 | 各 2.0% |
| 9/10 | 416/417 | 各 1.8% |
| 1–4 | 23–36 | 稀有 |

运行时存进 `bm[y][x]`,**低 4 位 = 地形,高 2 位(`0xC0`)= 占据标记**。

## `res/avatar/*.png` —— 武将头像

240 张,标准 PNG 未加密。42×51(6 张为 42×50),4-bit 调色板,平均约 1 KB。

## `res/music/*.mid`

已知字段偏移:每城记录 **offset 17** = `q[]`。
