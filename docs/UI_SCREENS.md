`aZ` 就是当前画面 ID。调试串 `curScreenID:` / `nextScreenID:` 证实了这一点。

## 战斗流程(ID 22)的子状态机

`z()` 内部再按 `this.am` 分派:

| 子状态 | 函数 | 内容 |
|---|---|---|
| 0(`au>0`) | `B()` | 阵亡演出 —— 「战亡沙场」 |
| 0(`au==0`) | `A()` | 攻击演出 —— 「攻击敌方中」「成功招降」「招降失败」 |
| 1/2/3 | — | 其它阶段 |
| 收尾 | `C()` | 叠加层 |

## 阵型选择的位置

**不是独立画面。** 它在 `F(Graphics)`(c.java:2643)里,
通过 `this.g = "阵型选择"` 设置标题,由战斗流程内部调用。
同一区间(2572–2915)还有 `E` `G` `H` `I` `J` `K` `L` 等一批战斗子绘制函数。

## ⚠️ 不存在「城市布局画面」

原版**没有**独立的城市建设/布局视图。容易混淆的两件事:

1. **`res/map/*.map` 36 张**是每座城的**战场地形**(32×20 格),
   只在开战时由 ID 20 使用,不是城市外观。
2. **「进入村庄」**(c.java:4767)是大地图上的**随机事件**,
   不是一个可进入的场景画面。

城市相关的画面只有三个:
ID 6 城内管理(指令条)、ID 13 城市详情(农业/工业/人口)、ID 8 内政菜单。
