### 指令菜单是叠上来的一层

`n()` 末尾 `if (br) T(graphics)`。`T()` 从 `lib307`(148×147,7 行 × 21px)取两行:

```java
drawRegion(lib307, 0, 0,          148,21, 0, 88, 201, 33);   // 第 0 行 = 底板
drawRegion(lib307, 0, (bn+1)*21,  148,21, 0, 88, 201, 33);   // 第 bn+1 行 = 该类指令
drawRect(21 + 36*bo, 183, 26, 14);                            // 黄框,bo = 四选一
```

## ⚠️ 不存在「城市布局画面」

原版**没有**独立的城市建设/布局视图。容易混淆的两件事:

1. **`res/map/*.map` 36 张**是每座城的**战场地形**,

   不是一个可进入的场景画面。

城市相关的画面只有三个:

## ID 20 战棋战场：逐格铺地形块 **[已验证]**

战场**不是整张图**，是按格子铺 16×16 的小块拼出来的。

| | |
|---|---|
| 地形块条 | `res/lib31.jg` —— 336×16，**21 个 16×16 的块**（林 / 水 / 灌木 / 池 / 树 / 帐篷 / 雪地 / 冰 / 房屋 / 岩石…） |
| 格子数据 | `res/map/<城ID>.map` —— **纯文本 CSV**，CRLF 换行，**32 列 × 19 行** |
| 可视窗口 | **11 列 × 13 行** = 176×208 px，正好铺满 176×220 的屏幕，靠 `t`/`u` 偏移滚动 |

```java
// c.O()：n 是行(<13)，n2 是列(<11)，t/u 是滚动偏移
int n3 = this.b.bm[n + this.u][n2 + this.t] & 0xF;
...重映射...
graphics.drawRegion(this.bb[4], n3 * 16, 0, 16, 16, 0, n2 * 16, n * 16, 20);
```

### 存的数字不是块号，中间有一层重映射

```
0        → 块 6
1, 3, 4  → 块 16
2        → 块 17          （`b(x,y)` 用 `!=2` 判通行，所以 2 是水/障碍）
5        → 先画块 5，再盖块 7   ← 唯一一个要叠两层的
6        → 块 13
7 … 12   → 块 9
其余      → 直接当块号
```

不照这张表走，渲出来会全错。`extract/mapgen/render_battlemap.py` 照抄了这段逻辑，
可以把任意一座城的战场还原成 PNG 复验：

```bash
python3 extract/mapgen/render_battlemap.py 19 work/_bm19.png   # 陈留
```

### 高清地块的管线

原版 21 个 16×16 的块换成 **64×64 的像素画**，格数与 `.map` 数据一条不动。

选像素画而不是厚涂：战场是硬边方格拼的，厚涂会在格子交界露出直缝，
得另做过渡混合；像素画里硬边本来就是该有的样子。

**生成的图不是无缝的**——提示词里写了「四边无缝平铺」，模型做不到，
3×3 一铺就能看见接缝。不用跟提示词较劲，`extract/mapgen/make_tile.py` 程序修：

1. 把图循环位移半格——位移版的四边正好是原图的中心，天然连续
2. 用「边缘权重高、中心权重低」的 smoothstep 掩码把两版混合，边界就接上了
3. `Image.BOX` 整数倍降采样到 64×64，再 `quantize` 限到 12 色，回到像素画

```bash
python3 extract/mapgen/make_tile.py <生成图> <输出> 64 12
```

### 一套主题 13 张

地形码只有 0–12 在用（扫过 36 张 `.map`），13–15 从没出现。所以一套主题要 13 张：

| 码 | 槽位 | 消耗 平/水/山 |
|---|---|---|
| 0 | `ground` 平地 | 2/3/3 |
| 1 / 3 / 4 | `wuku` 武库 / `cang` 常平仓 / `yao` 药庐 | 2/3/3 |
| 2 | `block` 障碍 | 6/6/6 |
| 5 | `ambush` 埋伏点 | 5/5/5 |
| 6 | `water` 水 | 5/**3**/6 |
| 7–12 | `r1`…`r6` 山林 | 5/6/**3** |

**7–12 是六个独立的码但消耗完全一样**——白送六种长相（岩峰 / 密林 / 灌木 /
垂柳 / 乱石 / 草坡），同一片「山地」里就有层次，不用改任何逻辑。

建筑格（1/3/4/2）不做无缝：它是「一样东西摆在本主题的地面上」，
四邻本来就是别的地形。

### 还要统一色板

13 张各自量化的话，黄绿草、青绿林、褐土、灰岩摆在一起像四套美术。
`extract/mapgen/unify_palette.py` 把整套拼成一张求一个 40 色的公共色板，
再让每张按它重新量化，整套调子就一致了。
