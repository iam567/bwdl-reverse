# 城内视图

从大地图点进一座城之后看到的画面：一张这座城的全景图，
玩家点图上的建筑进入对应的指令菜单。

## 建筑名用汉末本名

原先设想的**军机处、内务府、外交部、县委办公室都不是汉末的建制**——
军机处是清雍正七年(1729)设的，内务府是清代，外交部要到清末外务部(1901)，
县委办公室是现代。汉末郡城主官是**太守**，下设诸曹分司，按职能对应:

| 菜单 | 建筑 | 依据 |
|---|---|---|
| 人事 | **功曹府** | 功曹是郡吏之首,**主选署功劳**——选举、考课、任免 |
| 军事 | **校场** | 征兵、点兵、出征之所,比「兵曹」更有画面 |
| 内政 | **太守府** | 郡治正堂,开垦/劝商/治水/巡查都是太守本职 |
| 外交 | **驿馆** | 汉代邮驿接待使者之所,同盟/离间/招揽/情报靠使者与细作往来 |

集市四项按原版 `x[]` 位掩码逐城配置(见 GAME_LOGIC),也换成汉末名:

| 原版 | 汉末名 | 依据 |
|---|---|---|
| 金粮兑换 | **常平仓** | 汉宣帝始设,平抑粮价、以钱易粮 |
| 武器店 | **武库** | 汉代设武库令,郡国有武库 |
| 学院 | **郡学** | 文翁在蜀郡兴学,武帝令天下郡国皆立学校 |
| 医馆 | **药庐** | 汉代无「医院」建制,药庐/医庐是当时说法 |

界面标签写成「太守府·内政」这种形式:历史感保住,新玩家不用猜。

## 为什么是整图生成而不是拼装

先两种都做了一版洛阳对比:

- **拼装**——背景只出地面与远景,8 个建筑各做透明贴图按城拼上去。
  蒙版白送且精确,但拼出来的城散,像八个院子摆在空地上,没有城的整体感。
- **整图**——一次生成含全部建筑的完整场景。画面整体性和风格统一度明显更好,
  而且不同地域(北方积雪 / 南方竹林芭蕉)能做出明显差异。

选整图。`extract/mapgen/compose_cityview.py`(拼装版)已删除。

## 蒙版怎么来

整图的代价是蒙版要另外生成。做法是**把它当语义分割任务下达**,
不是当绘画指令——这是从 pic.areu.pro 那套已验证有效的提示词学来的要害:

```
根据输入的汉末郡城城内图生成同尺寸精确建筑语义蒙版。
保留每栋可点击建筑的实际外轮廓和原位置,纯黑背景,仅建筑轮廓内部填指定纯色。
太守府(…)=#FF0000;功曹府(…)=#00FF00;…
不用文字、阴影、渐变、描边或抗锯齿。
仅输出单张与输入严格逐像素对齐的分类图,不增加边栏、参考小图或拼贴,不重新构图。
```

第一版我写成了绘画指令（"把它重画成一张点击热区蒙版图…色块边界要贴着轮廓走"），
模型只描了一圈**彩色线框**,内部仍是黑的。换成上面这种分割任务的措辞后,
立刻变成填充色块。关键词是「语义蒙版」「仅轮廓内部填纯色」
「严格逐像素对齐的分类图」「不用描边或抗锯齿」「不重新构图」。

### 生成出来还要洗一遍

`extract/mapgen/clean_mask.py`。模型能把轮廓填对,但有三个毛病,程序修掉,
不用再跟提示词较劲:

1. **边缘抗锯齿** → 最近色量化(`Image.quantize(palette=…, dither=NONE)`),
   每个像素强制归到色表里某一色
2. **零星杂点**(远处一栋民房被涂成同色) → 先开运算去渣,再按连通域只留成块的。
   连通域标号用 `tobytes().find(b'\xff')` 在 C 层找下一个前景点,再 `floodfill` 打标
3. **院落内部留黑洞**(院子地面没填) → 从画面外围反向洪泛,够不到的黑区就是洞,填上

洗完输出 `<city>_mask.png` 和 `<city>.json`(每个建筑的色值、包围盒、像素数)。

**顺序要紧**:必须先开运算去杂点再标连通域。反过来的话碎块太多,
标号在 254 上限前就用完,整类建筑会被整个丢掉——郡学和药庐就这么消失过一次。

## 建筑名匾

每座建筑底边挂一块木匾,写「太守府·内政」。
底纹 `ui_plaque` 是生成的汉末木质匾额(深栗褐木板、四角鎏金角叶、板心留空),
裁剪后存为 `output/cityview/plaque.png`。

匾按文字长度伸缩,所以**横向三段拉伸**:左右两端各取原图 18% 宽度原样画,
中间一段拉伸。整块直接拉的话四角的铜件会被拉变形。

标签画在独立的 `#cvlbl` 画布上(在高亮层之上),
选中某座建筑时它的匾保持全亮、其余压到 38%。

## 点击判定与高亮

`preview.html` 把蒙版画进离屏 canvas,点哪读哪个像素的颜色,查色表得建筑。

**高亮直接用蒙版的形状,不画包围盒方框**——方框难看,而且蒙版本来就是精确的。
做法:把蒙版里颜色等于该建筑的像素取出来做成一张不透明剪影,拿它当模板——

1. 全画布铺一层暗色,再 `destination-out` 剪影 → 压暗四周,只留这座建筑
2. 把剪影放大几像素再挖掉原剪影 → 得到一圈沿轮廓的描边,上金色 + 外发光,随呼吸明灭
3. `overlay` 模式轻叠一层剪影 → 建筑本身微微提亮

**围墙有缺口的院落补洞会漏**——洪泛从缺口钻进院内,院子地面在蒙版上仍是黑的。
校场就是这种（围墙一圈,中间是演武空地）。所以读到黑色时再按**包围盒兜底**:
落在哪个建筑的包围盒里就算点中哪个,多个命中取面积最小的。

## 顶部城池数据栏

底纹 `ui_panel` 是生成的**帛书绢面 + 青铜框**（米黄素绢、织纹与折痕、四角铜件、
两侧铜环，绢心完全留空给排数据）。用 CSS `border-image ... 58 fill / 13px` 做九宫格拉伸，
所以铜框四角不会被拉变形。绢底是浅色，数字要用深褐 `#3a2a14` 才压得住。

数据来自 `extract/data/city-stats.json`（由 cities.csv + officers.csv 生成，
经 `/api/edit/cities` 的 `stats` 字段下发），一城 12 项：

| | | |
|---|---|---|
| 君主 | 太守 | 武将数 |
| 人口 | 兵力 | 治安 |
| 农业 | 商业 | 治水 |
| 黄金 | 粮草 | 规模 |

**令牌数**单独做成右上角的徽记（`clamp(己方城池数,3,8)`，见 GAME_LOGIC），
旁边是返回大地图的地图图标——返回不放在页面底部，那里要留给建筑指令面板。

排版上踩过的：第一版标签在数值上方另起一行、三列四行、间距宽松，
整个面板 230px 高，把城图挤得只剩一半还要滚动。
改成**标签与数值同一行**（`君主 献帝`）、行距压到 3px、边框从 13px 收到 11px 之后
降到 145px，城图在 375×812 上一屏放得下，八个建筑全露出来。
绢底是浅色，标签用深褐 `#6b5230` 加粗才够醒目，数值用更深的 `#2e2110`。

整屏背景是生成的 `ui_bg`（深栗漆木墙板 + 暗铜泡钉，平均亮度 32/255）。
纯黑背景太硬，木板底又暗又暖，压得住上面的绢面和城图。

## 建筑指令浮窗

第一版是底部通栏的抽屉，一弹出来盖掉小半张城图。改成**贴着被点建筑的小浮窗**：
宽 150px，四个候选位（右 / 左 / 下 / 上）各算两笔账——
压住这座建筑多少面积、超出画面多少——加权取最小，所以它总是从建筑旁边探出来，
而不是盖在它脸上。侧边有个小三角指回建筑。

底板 `ui_menu`（深栗木板 + 青铜雷纹包边 + 四角铜件）和按钮 `ui_btn`
（青铜片，起线包边，两端铜钉）都是生成的，用 `border-image` 九宫格。

按钮的切片要注意：铜钉在横向 90px 以内，所以切片写成 `30 90`（纵 30 横 90），
只切 30 的话铜钉会落进被拉伸的中段，变成椭圆。
铜面是中等偏亮的暖金，字必须用深褐 `#2a1c08` 加一道浅色上高光才压得住。

踩过一个坑：`#cvpic` 上有 `line-height:0`（消除图片的行内间隙），
浮窗放进去之后继承了它，文字高度塌成 0，整个浮窗看不见。

## 管线

```bash
# 1 生成城内全景（做法B）        平台 category=citybld
# 2 生成语义蒙版                 refItem 指向全景图，走 images/edits
# 3 洗蒙版
python3 extract/mapgen/clean_mask.py <蒙版png> work/cityview/<city>
# 4 全景转 jpg 一并上传
scp work/cityview/<city>.{jpg,json} work/cityview/<city>_mask.png \
    root@VPS:/var/www/sg.areu.pro/output/cityview/
```

前端 `CITY_VIEW` 表把城池 ID 映到文件名,没有条目就退回占位页。

## 36 座城怎么彼此拉开

第一批出来的城全长一个样——因为提示词里写死了「夯土主街分割成几个区块」，
等于给 36 座城套同一个模板。后来改成三层逐城差异：

**季节**按纬度给。辽东襄平深冬冰封、幽州北平大雪、并州晋阳初冬薄冰、
中原秋收、巴蜀早春江雾、江南早春细雨、荆南与南中盛夏。
提示词里明写「季节必须从植被、天光、地面和人物衣着上一眼看出来」。

**城建格局**按城的性质分七种，写在 `cities-detail.js` 的 `LAYOUT`：

| 格局 | 城 |
|---|---|
| 里坊棋盘 | 长安 洛阳 邺城 |
| 十字通衢 | 成都 零陵 长沙 陈留 寿春 濮阳 淮南 平原 徐州 北海 |
| 依山盘曲 | 梓桐 江州 汉中 上庸 桂阳 |
| 水街交织 | 庐江 建业 会稽 |
| 临江一线 | 襄阳 江陵 江夏 豫章 广陵 |
| 军屯直街 | 西平 武威 天水 晋阳 北平 襄平 |
| 寨落散布 | 云南 建宁 山越 荑州 |

**风土人情**逐城写：武威的驼队胡商、云南的铜鼓与干栏楼、汉中的五斗米道义舍、
北海的讲经与盐田、桂阳的冶铁炉火、荑州的独木舟与贝饰。

### 汉代形制约束

生图模型默认画明清宫殿，必须逐条堵。`HAN_ERA` 那段禁掉了
飞檐翘角、斗拱彩画、琉璃瓦、红灯笼（唐以后才有）、桌椅（汉人席地跪坐）、
青花瓷（用漆器灰陶）、佛塔，并规定人物着深衣曲裾、束发戴帻。

### 没有的设施不能画

四类集市设施是逐城配置的。光在正面清单里不提不够——
模型会顺手把粮囷、兵器架这类眼熟的东西补进去。
`absentClause()` 把缺席建筑的标志物逐条点名禁掉，
比如没有郡学的城，连半月形泮池、石桥和刻经石碑都不许出现。

### 两座建筑撞标志物会被合并

功曹府原先写「院中立着一块石碑」，和郡学的「刻经的高石碑」撞了。
8 建筑的满配城画面一挤，模型就把这两座并成一座——
成都连跑两次整图、三次蒙版都少功曹府。
改成功曹府独占「成捆竹简 + 木榜栏」、明写「绝不能有石碑或水池」，
并在清单前加一句「共 N 座，必须全部出现，不能把其中两座合并」，一次就对了。

## 现状

**36 座全部完成**，共 238 个可点击建筑，逐城核对无缺无多。
`extract/mapgen/batch_cityview.py` 会把每座城的蒙版洗干净并核对建筑数：
本城该有几个（4 个必有 + `x[]` 位掩码里的集市设施）对上蒙版实际洗出几个。

核对时发现的三座：江陵、淮南是**图里有、蒙版没认出来**，
只重跑蒙版（1 张）就好了；成都是**整图真没画**，得重跑整图。
先重跑蒙版再决定要不要重跑整图，能省下不少生成。
