# 有意偏离原版的地方

这里只记**明知道原版是什么样、仍然决定改**的条目，以及改法和怎么改回去。
「还没挖到所以先顶着」的临时实现不属于这里，那些记在 `GAME_LOGIC.md` 对应小节的
**[未确认]** 标记里。

| 条目 | 原版 | 我们改成 | 出处 |
|---|---|---|---|
| 呐喊 | 攻击力 **×1** | 全军攻击力 **×1.5** | §9.15 |
| 火矢 | 弓兵攻击力 **×1** | 弓兵攻击力 **×2** | §9.15 |

## 呐喊 / 火矢

原版 `b.V()` 里这两个增益乘的都是 1：

```
165: iload_3   166: iconst_1   167: imul      // cd&0xF0 == 64  呐喊
203: iload_3   204: iconst_1   205: imul      // cd&0xF0 == 80  火矢（且 bU==2）
```

这不是反编译丢了乘数——`javap -c b.class` 看字节码就是硬编码的 `iconst_1`。
说明文案写着「全军攻击力增加」「箭手攻击力大大增加」，但代码里没接。
六个计策点能力里**只有连弩是真的**（射程 `by2` 由 5 变 7，即 4 格 → 6 格）。

花 8 点和 10 点计策点买不到任何效果，显然不是设计意图，所以接上：

```csharp
// BattleRules.BuffMul()
case 4: return 1.5f;                          // 呐喊：全军
case 5: return arm == Arm.Gong ? 2f : 1f;     // 火矢：只加弓兵
```

**要回到原版行为**：把 `BattleRules.BuffMul()` 的返回值全改成 `1f`。
增益的编码、持续回合、消耗的计策点都照原版没动
（`cd` 高 4 位能力号、低 4 位剩余回合，每轮减 1）。

## 战棋层计策：两处原版没给数

16 种计策的落点合法性（`b.a(int,int,byte,boolean)`）、成功率与伤害（`b.a(short,short,byte,short)`）、
结算（`b.a(short,byte[],byte,byte,int,boolean)`）都是逐段移植的，见 `BattleRules.PlotLegal / PlotRoll / PlotMessage`。
顺带发现 **劫火（14）在原版永远用不出去**——合法性函数 2349 那两行两个分支都 `return false`。菜单里置灰。

两处原版没给数、我定的：

| 项 | 我定的 | 依据 / 怎么改 |
|---|---|---|
| 被困几日（虚兵 4 / 连环 7 / 奇门遁甲 17） | 三种都 **3 日**，奇门遁甲每日再减 100 兵 | 说明文案 `d.q[10]`「被困三天」、`d.q[15]`「日减100兵」；代码里没找到 `bv` 递减处。改 `BattleField.TRAP_DAYS` |
| 十面埋伏踩中扣多少兵 | **150** | 原版 3703 走 `E(); j(...)`，没读到数；按共杀那档。改 `BattleField.AMBUSH_LOSS` |

## 主公不豁免：也能劝降 / 笼络 / 俘虏

原版把「忠诚 > 99」当主公标记：单挑劝降 `b.k()` 第一行直接 `return false`，
情报和列表里忠诚画「--」。我们的设定是**主公到最后也能被劝降、笼络、俘虏**：

| 处 | 原版 | 我们 |
|---|---|---|
| 单挑劝降 `Persuade` | `P > 99 → false` | 去掉这一行，忠诚 100 照常进公式（要把体力打到个位数才可能） |
| 计策笼络 `PlotRoll(8)` | `P > 35 → false` | 不变（主公 100 本来就过不了 35 这关，靠单挑劝降那条路） |
| 情报 / 列表显示 | `--` | 显示 100 |
| 战后俘虏 | 战略层未接 | 接的时候主公不豁免 |

劝降公式里的 `n`：原版只特判 `4→6、5→8`，德智都 100 时 `x=101` 落进 6 那格没特判，
反而比 95 档低。我们把 `n ≥ 5` 一律抹成 8。回原版改回 `else if (n == 5) n = 8;`。

要回到原版：`Persuade` 加回 `if (foe.Loyal > 99) return false;`，显示处改回 `--`。

## 待定：地形码 1 / 3

原版给了 1 和 3 两个独立地形码，踩上去只是结束行动，没有任何效果
（见 `GAME_LOGIC.md` §8.2）。据玩过其他版本的玩家回忆，那边是**武器店 / 金粮店**。
美术上已经按武库 / 常平仓画成两种不同的房子，**效果补不补是个待定的设计选择**，
补了就是回到其他版本的样子。
